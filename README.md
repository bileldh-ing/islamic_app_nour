# نور — Noor

تطبيق إسلامي متكامل بتصميم «زجاج سائل» فاخر (Flutter، واجهة عربية بالكامل RTL).

## المزايا
- **أوقات الصلاة** حسب موقعك (مكتبة Adhan الفلكية) مع ١٩ طريقة حساب (منها تونس، أم القرى، رابطة العالم الإسلامي)، المذهب الحنفي/الجمهور، تعديل يدوي بالدقائق، منتصف الليل والثلث الأخير.
- **الأذان**: إشعارات دقيقة بصوت أذان كامل (CC0 من Wikimedia Commons)، تذكير قبل الصلاة، أذكار الصباح والمساء، سورة الكهف يوم الجمعة، تذكير صيام الإثنين والخميس والأيام البيض وعرفة وعاشوراء.
- **القبلة**: بوصلة حقيقية (مستشعر الجهاز) مع تنعيم، اهتزاز عند المحاذاة، خريطة تُظهر خطك إلى الكعبة والمسافة بالكيلومتر.
- **القرآن الكريم** كاملًا دون إنترنت: ١١٤ سورة، ٦٢٣٦ آية بالرسم العثماني، **التفسير الميسر تحت كل آية**، ترجمة إنجليزية (صحيح إنترناشيونال) وفرنسية (حميد الله) اختيارية، تلاوة آية بآية لستة قرّاء، بحث في الآيات، الأجزاء، المحفوظات، متابعة القراءة.
- **الأذكار والأدعية** من حصن المسلم مع عدّاد لكل ذكر، **التسبيح** الإلكتروني، **متابعة الصلاة** (سلسلة الأيام ونسبة الشهر)، **التقويم الهجري** مع المناسبات، **أسماء الله الحسنى**، **الشهادة**، **الصيام** (السحور والإفطار وسجل الصيام).

## التشغيل
```bash
flutter pub get
dart run flutter_launcher_icons
flutter run
```
كل دفع إلى `main` يبني ملف APK تلقائيًا عبر GitHub Actions (تبويب Actions ← Artifacts).
